# Seguridad

ISLA está en fase beta. La app usa firma ad hoc y no está notarizada; no se ofrece una garantía de revisión de seguridad externa.

Para un fallo funcional, usa la plantilla de bug. Si descubres una vulnerabilidad que expone datos o permite ejecutar acciones no deseadas, utiliza **Security → Advisories → Report a vulnerability** si el repositorio tiene activados los reportes privados. Si no está disponible, pide al mantenedor un canal privado sin publicar detalles explotables ni datos personales en un issue.

No adjuntes portapapeles, notas, emparejamientos de dispositivos, credenciales, certificados ni archivos privados. Una reproducción mínima con datos ficticios suele ser suficiente.

La versión de referencia actual es 0.13.x. No se promete soporte de versiones antiguas, tiempos de respuesta ni compatibilidad futura con el framework privado MobileDevice. La licencia no cambia los permisos de macOS ni los requisitos de los servicios externos.
